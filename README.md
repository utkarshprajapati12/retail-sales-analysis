# Retail Store Sales & Performance Analysis

## Overview
This repository contains an end-to-end exploratory data analysis project on retail transactions. The goal of this project is to analyze customer buying behavior, identify top-selling product categories, and calculate core business performance KPIs using SQL.

## Project Structure
- `sales_data.csv`: Transaction dataset containing order records, customer details, and regional metrics.
- `queries.sql`: SQL scripts for database schema creation and business insight queries.

## Key Business Insights Solved
1. **Total Revenue & Volume:** Calculated total orders, aggregate revenue, and average transaction value.
2. **Category Performance:** Ranked product categories by total sales.
3. **Top Revenue Drivers:** Identified top 5 best-performing products using SQL aggregation.
4. **Regional Distribution:** Analyzed sales distribution across North, South, East, and West regions.

## Tech Stack
- **Database / Querying:** SQL (MySQL / PostgreSQL)
- **Data Handling:** CSV / MS Excel
- **Visualization:** Microsoft Power BI
